## 💡 Project Overview

This mini project generates a random number between **1 and 10**. The user has to guess the correct number. Based on the guess, the program provides hints whether the number is higher or lower until the correct answer is guessed.

---

## 🎯 Features

- Generates a random number.
- Takes user input repeatedly.
- Provides higher/lower hints.
- Counts the number of attempts.
- Displays a success message after the correct guess.
